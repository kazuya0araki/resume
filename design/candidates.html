Notes

公開の仕組み

いずれの案も docs/ に静的 HTML を置き、GitHub Pages の Source を main / docs にするだけで公開できます（Jekyll テーマは使わず自前 CSS）。

README.md を原稿のままにして、GitHub Actions でビルドし直す構成にすれば、これまでどおり README を更新するだけでサイトも更新されます。

共通で入れる予定のもの

  • 日本語 / English 切り替え（README_EN.md 対応）
  • 印刷・PDF 用のスタイル（A / C は特に相性良）
  • OGP 画像と meta description
  • スマートフォン表示の最適化

先に決めたいこと

  • 生年月日・性別を公開ページに載せるか（README には現在記載あり。Web 公開では省略を推奨します）
  • 顔写真の有無（C 案はイニシャル表示で代替中）
  • 独自ドメインを当てるか、github.io のままにするか
