訳が同じ値は**スカラー 1 つ**で持ち、異なる値だけ `ja` / `en` のマップにする。

```yaml
role: Data Engineer                # 日英で同じ
org:
  ja: プラットフォーム開発部 データプラットフォームグループ
  en: Platform Development Department, Data Platform Group
```

言語に依存しない情報（日付・URL・数値）は 1 度しか書かない。
そのため、日英で日付や URL がずれるという事故が構造的に起きない。

移行前は `README.md` と `README_EN.md` の二重管理により、
期間の不一致 3 箇所・表の項目数の不一致 3 箇所・URL 133 個の二重記載が発生していた。

言語ごとの表記は生成側が組み立てる。`meta.labels` を参照のこと。
