`data/` 配下のファイルは章ごとに分かれている。章の出力順は [meta](meta.md) の `sections` が持つ。

| ファイル | 章 | 内容 |
|---|---|---|
| [`data/meta.yml`](meta.md) | 全体設定 | 更新日・対応言語・章の並び・生成時に使う固定語彙。 |
| [`data/basic.yml`](basic.md) | 基本情報 | 氏名・生年月日・性別・居住地と SNS アカウント。 |
| [`data/career.yml`](career.md) | 職務経歴 | 在籍企業と、企業ごとの所属組織・職位・業務内容。 |
| [`data/qualifications.yml`](qualifications.md) | 資格 | 保有資格の一覧。 |
| [`data/skills.yml`](skills.md) | スキル | 念能力6系統・ポートフォリオと、OS / 言語 / ミドルウェア / クラウド / IDE / ツールの各区分。 |
| [`data/mission.yml`](mission.md) | Mission / Vision / Value | 行動指針と座右の銘。 |
| [`data/achievements.yml`](achievements.md) | 実績 | 登壇・メディア掲載・著書。 |
| [`data/interests.yml`](interests.md) | 興味があるもの | データ × 他分野の関心領域と読書。 |
| [`data/aspirations.yml`](aspirations.md) | どんなことがしたいか | 今後取り組みたいこと。 |
